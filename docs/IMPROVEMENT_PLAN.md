# 꽃돼지 vs 청토끼 — 뱀파이어 서바이버즈식 개편 계획안

> 대상: `game.js`(5,555줄 단일 파일), `index.html`, `style.css`, `service-worker.js`
> 목표: ① 성능 안정화(모바일 60fps, 적 300+ 동시) ② 뱀서식 성장 루프(무기·패시브·진화·보스 보상) ③ 그로테스크 호러 톤의 UI/UX

---

## 0. 현재 구조 진단 요약

| 영역 | 현재 상태 | 문제 |
|---|---|---|
| 게임 형태 | 플레이어 x 고정·상하 이동만, 자동 사격 1종, 적은 오른쪽에서만 등장 | 뱀서식 "포위당하는 공포"와 빌드 다양성이 없음 |
| 성장 | `LevelSystem`(game.js:1661) — 플레이어 레벨은 HP/방어만, 아이템 4종은 게이트 통과로 EXP 획득 | 선택의 재미가 없음(게이트 2택이 전부), 레벨업 = 숫자 증가뿐 |
| 아이템 | `GatePair`(game.js:2320) 8종 중 랜덤 2개 | 무기 종류가 사실상 1개(+꽃잎포, 폭탄) |
| 보스 | `Boss`(game.js:3030) 스프라이트 3종, 상하 이동 + 공격 + 킹만 분노 모드 | 패턴이 단조롭고 처치 보상이 EXP 100뿐 |
| 루프 | `gameLoop`(game.js:4065) 프레임 기반 이동, deltaTime 없음 | 120/144Hz 기기에서 게임이 2배속, 저사양에선 슬로모션 |
| 렌더 | `shadowBlur` 61회, 매 프레임 그라디언트 생성, `Date.now()` 49회 | 모바일 GPU에서 가장 비싼 연산이 매 프레임 반복 |
| 코드 | 전역 변수 + 단일 파일 | 기능 추가 시 회귀 위험 큼 |

## Phase 1 — 성능 기반 공사 (가장 먼저, 약 1주)

뱀서식으로 적 수를 10배 늘리면 현재 구조는 바로 무너지므로 이것부터 합니다.

### 1-1. 고정 타임스텝 게임 루프
- `gameLoop`를 `update(dt)` / `render(alpha)`로 분리, 누적기 방식 고정 스텝(1/60s).
- 하드코딩된 프레임 상수 제거: `Player.shield -= 16`(game.js:1524), `n.timeLeft -= 16`(1529), `ft.life -= 0.02`(4180), 모든 `x -= speed` → `speed * dt`.
- 탭 비활성 복귀 시 dt 클램프(최대 250ms)로 순간이동 방지.

### 1-2. 핫패스 정리 (즉시 효과, 반나절)
- 사격·피격마다 찍히는 `console.log` 제거: game.js:1561(매 발사), 4105(매 피격). 전체 47개는 `DEBUG` 플래그로 래핑.
- `updateMainMenuVisibility/InstallButton/GameOverButton`(4083-4085) DOM 갱신을 매 프레임이 아닌 **상태 전환 시 1회**로.
- `Date.now()` → 루프의 `timestamp` 전달로 통일.
- 스킬 알림 그라디언트(4226, 4246) 매 프레임 생성 → 캐시.

### 1-3. 오브젝트 풀 + swap-remove
- `Projectile`, `Particle`, `Enemy`, `FloatingText`, (신규) `XpGem` 모두 풀링. `new` 금지.
- `splice` 순회 제거(4096-4181) → 활성 개수 기반 swap-remove. 대량 사망 시 GC 스파이크 제거.
- `createExplosion`(3365) 15개 파티클/킬 → 화면 내 파티클 상한(모바일 300, PC 800) + LOD.

### 1-4. 렌더링 비용 절감
- `shadowBlur` 전면 제거 → **사전 렌더링된 글로우 스프라이트**(OffscreenCanvas에 1회 그려 `drawImage`), 가산 합성은 `globalCompositeOperation='lighter'`.
- 적 스프라이트 프레임을 시작 시 슬라이스해 캐시 → 매 프레임 `drawImage(9-인자)` 크롭 계산 제거.
- HUD를 정적 레이어(프레임/아이콘)와 동적 레이어(수치)로 분리, 정적은 오프스크린 캐시.
- 배경은 별도 `<canvas>` 레이어로 분리(게임 캔버스 아래), 패럴랙스만 갱신.
- `devicePixelRatio` 대응 + 모바일은 내부 해상도 0.75 스케일 옵션.

### 1-5. 충돌 판정
- 현재 탄환×적 O(P·E) 이중 루프(4097-4116) → **균일 그리드 공간 분할**(셀 128px). 적 300 × 탄 200에서도 안정.
- 적끼리 겹침 방지(soft separation)도 같은 그리드 재사용 — 뱀서 특유의 "밀려오는 무리" 느낌의 핵심.

### 1-6. 에셋/로딩
- 배경 PNG 5장(각 670~920KB) → WebP 변환(예상 70% 절감), BGM은 128kbps 재인코딩.
- `service-worker.js`: 현재 쿼리스트링 요청(`game.js?v=4`)은 캐시를 우회하고 에셋은 아예 캐시 안 함 → 버전 해시 기반 프리캐시 + 에셋은 cache-first.
- 로딩 화면에 진행률 표시(현재 `ImageLoader` 완료 대기 UI 없음).

### 1-7. 코드 구조 분리 (기능 개발 전 필수)
단일 `game.js` → ES 모듈(번들러 없이 `<script type="module">` 가능):
```
src/
  core/      loop.js, input.js, pool.js, spatialGrid.js, audio.js, assets.js
  entities/  player.js, enemy.js, boss.js, projectile.js, pickup.js
  systems/   weapons/, passives.js, evolution.js, leveling.js, spawner.js, waves.js
  ui/        hud.js, levelUpModal.js, bossBar.js, screens/
  data/      stages.js, weapons.js, enemies.js, bosses.js, story.js
```
스토리 텍스트(STAGE_DATA 내 장문)는 `data/story.js`로 분리해 로직과 분리.

**완료 기준:** 저사양 안드로이드에서 적 300 + 탄 200 + 파티클 300 동시 60fps, 120Hz 기기에서 게임 속도 동일.

## Phase 2 — 뱀서식 코어 루프 (약 2주)

### 2-1. 이동/전장 개편 (권장안)
- **플레이어 8방향 자유 이동**(조이스틱이 이미 있음: `virtual-joystick`) + 화면은 횡스크롤 유지.
- 적은 주로 오른쪽에서 오되, 웨이브에 따라 **위·아래·뒤(왼쪽)에서 포위 등장** → 뱀서의 포위 공포 확보, 기존 배경/연출 자산은 그대로 활용.
- 스테이지 목표를 "킬 수"에서 **"생존 시간(예: 5분) + 마지막 보스"**로 전환. 시간대별 웨이브 테이블(`data/waves.js`).

### 2-2. 경험치 젬 & 레벨업 카드
- 적 사망 시 **XP 젬 드롭**(크기·색 3단계: 살점 조각 → 썩은 심장 → 푸른 결정). 자석 범위 패시브로 흡수.
- 레벨업 시 게임 일시정지 + **3택 카드**(무기 신규/강화, 패시브 신규/강화). 리롤·스킵·봉인(Banish) 횟수는 메타 진행으로 해금.
- 기존 `GatePair`는 폐지하지 않고 **"저주 게이트"**로 재활용: 좌우 중 하나 통과 시 강한 버프 + 디버프(예: 공격 +30% / 최대 HP -20%) — 리스크·리워드 선택.
- 기존 `addPlayerExp`/`addItemExp` 이원 구조는 단일 EXP로 통합.

### 2-3. 무기 (최대 6슬롯, 각 Lv.8)
테마: 연이의 총기 + 꽃돼지 일족의 연꽃 주술.

| 무기 | 동작 | 진화 조건(패시브) → 진화 무기 |
|---|---|---|
| 12게이지 산탄총 (기본) | 전방 부채꼴 산탄 | 탄창 확장 → **도살자의 산탄**(관통 + 출혈) |
| 쌍권총 | 가장 가까운 적 자동 조준 연사 | 집중 → **처형인의 쌍권총**(헤드샷 즉사 확률) |
| 연꽃 가시 | 플레이어 주위 공전 | 회전 수액 → **피의 연꽃**(흡혈 오라) |
| 노획 소총 | 관통 직선 저격 | 조준경 → **레일 소총** |
| 화염병 | 바닥 지속 화염 장판 | 확산 → **지옥 불꽃 길** |
| 꽃잎 포 (기존 필살기) | 차지형 대형 빔 | 꽃가루 → **만개(滿開)** |
| 연막·독가스 수류탄 | 범위 둔화+도트뎀 | 독샘 → **역병 안개** |
| 뼈 톱날 | 튕기는 원반 | 날 연마 → **척추 분쇄기** |

### 2-4. 패시브 (최대 6슬롯, 각 Lv.5)
탄창 확장(투사체 수), 집중(치명타), 회전 수액(지속시간), 조준경(사거리), 확산(범위), 꽃가루(쿨감), 독샘(상태이상), 날 연마(피해), **썩은 심장**(최대 HP), **피 맛**(흡혈), **자석 코**(획득 범위), **광기**(이속, HP 낮을수록 공격력↑).
- 기존 SHIELD/SUPPORT/HEAL/BOMB는 무기·패시브가 아닌 **필드 드롭 아이템**(상자, 촛대 파괴)으로 이동.

### 2-5. 적 다양화
`data/enemies.js`에 행동 타입 정의:
- **러너**(기존 청토끼), **스피터**(산성 투척, 기존 `enemyShoot`), **팽창체**(사망 시 폭발), **기생체**(죽으면 소형 3마리 분열), **집단 무리**(30마리 일렬 돌진 이벤트), **엘리트**(크기 1.5배, 보물상자 드롭).
- 스테이지별 HP 곡선은 현재 선형(120→800, game.js:2108) → 시간 기반 스케일링 + 웨이브 테이블로 대체.

## Phase 3 — 보스전 개편 (약 1.5주)

### 3-1. 보스 공통 구조
- **페이즈 3단계**(100-60% / 60-25% / 25-0%), 페이즈 전환 시 연출(화면 정지 0.3s, 피 튀김, 보스 변형).
- 패턴 = 데이터 정의(`data/bosses.js`): 탄막(원형/나선/조준), 돌진(예고선 표시), 소환, 장판, 그랩(잡기 → 연타 탈출).
- 모든 위험 공격에 **예고 텔레그래프**(붉은 영역 0.6~1s) — 난이도는 올리되 억울함은 줄임.
- **보스 처치 보상 = 보물상자**: 룰렛 연출로 1/3/5개 업그레이드 지급, 진화 조건 충족 시 진화 우선.

### 3-2. 보스 라인업 (기존 BOSS_QUOTES 계승)
| 스테이지 | 보스 | 핵심 패턴 |
|---|---|---|
| 1-2 | 알파/엘리트 청토끼 | 돌진 + 소환, 튜토리얼 성격 |
| 3 | 헌터 | 독안개 속 은신 → 안광만 보이는 상태로 기습 |
| 4 | 프레데터 알파 | 레이저 조준선 저격, 엄폐 오브젝트 활용 |
| 5 | 탱크 | 거대 탄막, 약점(등 종양) 노출 시 2배 피해 |
| 6 | 어보미네이션 | 융합체: 팔·다리를 개별 파괴(부위 HP), 산성 장판 |
| 7 | 어쌔신 퀸 | 순간이동 + 분신, 진짜만 피격 |
| 8 | 사이코틱 킹 | 환각 페이즈: 화면 반전/색 왜곡, 가짜 적(가족 환영) 섞임 |
| 9 | 브루투스 킹 | 왕좌 고정 + 안구 포탑 다수 파괴 |
| 10 | 얼티메이트 원 | 과학자 융합체: 3페이즈 총집편 + 신경삭 촉수 차단 |

- 중간보스(엘리트) 2분마다 1회, 최종 보스 전 **"군체 러시"** 30초 생존 이벤트.

## Phase 4 — 그로테스크 UI/UX (약 1.5주, Phase 2와 병행 가능)

### 4-1. 아트 디렉션
- 톤: **"네온 + 살점"** — 기존 네온 시티 팔레트에 핏빛 크림슨(#8b0000), 썩은 녹청(#3a5f3a), 담즙 황(#b8a038), 청토끼 블루(#2c5ea8) 추가. CSS 변수로 토큰화.
- 질감: 프레임/패널에 **살점·힘줄·꿰맨 자국·혈관** 9-slice 스프라이트, 미세한 맥동(scale 1.0↔1.02) 애니메이션.
- 폰트: 기존 `Press Start 2P` 유지 + 경고/보스명은 번지는 잉크 효과(텍스트 그림자 대신 사전 렌더 스프라이트).

### 4-2. HUD 재설계
- **HP 바 = 박동하는 혈관**: HP 낮을수록 박동 빨라지고 화면 가장자리에 붉은 비네트 + 심장 박동 SFX.
- **EXP 바**: 화면 상단 전체 폭, 바늘 꿰맨 자국 모양, 레벨업 직전 맥동.
- 무기/패시브 슬롯 아이콘 12칸(좌상단), 타이머(중앙 상단), 킬 수(해골 아이콘).
- 보스 HP 바: 화면 하단 대형, 페이즈 구간 눈금, 피격 시 지연 감소(흰색→빨강 트레일).
- 기존 DOM HUD(`hud-container`)와 캔버스 HUD(`drawHUD`, game.js:99) 이중 구조 → 하나(캔버스)로 통일.

### 4-3. 레벨업 카드 화면
- 배경 정지 + 채도 저하 + 피 번짐 트랜지션.
- 카드: 해부도/실험 보고서 스타일(“프로젝트 블루 래빗” 기밀문서 톤), 신규=NEW 붉은 도장, 진화 가능=맥동 테두리.
- 모바일: 카드 탭, PC: 1/2/3 키 + 마우스. 실수 방지 0.3s 입력 잠금.

### 4-4. 타격감 / 주스(Juice)
- 히트스톱(보스·엘리트 처치 40~80ms), 피격 흰색 플래시, 데미지 숫자(치명타는 크고 붉게).
- 고어 레이어: 사망 시 **피 웅덩이 데칼**(오프스크린 캔버스에 누적 → 비용 거의 0), 살점 파편 파티클, 시체 잔상 페이드.
- 화면 흔들림은 강도·횟수 상한 + 설정에서 끄기.
- 상태이상 시각화: 출혈(붉은 방울), 독(녹색 거품), 화염.

### 4-5. 화면 흐름
- 타이틀: 맥동하는 살점 프레임 안 로고, 안개 파티클, 메뉴 hover 시 핏방울 낙하.
- 게임오버: 기존 이미지 + **런 결과**(생존 시간, 처치 수, 무기별 피해량 표) — 다음 판 동기 부여.
- 스토리(타자기 연출) 유지하되 **스킵 버튼 상시 노출** + 첫 클리어 이후 자동 축약.

### 4-6. 접근성/옵션
- 설정 메뉴: 고어 수위(끔/보통/최대), 화면 흔들림, 플래시 감소, 데미지 숫자, BGM/SFX 볼륨, 성능 모드(파티클·해상도).
- 색약 대응: 적 탄은 색 + 형태(가시 모양)로 구분.

## Phase 5 — 메타 진행 & 마감 (약 1주)

- **골드(코인) 영구 강화**: 최대 HP, 공격력, 이속, 자석, 리롤/봉인 횟수 — `localStorage` 저장.

## 구현 현황 (1차 구현 완료)

장르를 **8방향 이동 서바이버**로 완전히 전환했고, 고어 수위 기본값은 **보통**입니다.

### 구조
```
index.html, style.css          DOM UI (타이틀/스토리/레벨업/관 상자/일시정지/설정/상점/결과)
src/main.js                    부트 + 고정 타임스텝(1/60s) 루프, ?debug 성능 오버레이
src/core/                      settings · save(메타) · pool · grid(공간분할) · input · audio · assets
src/data/                      stages · enemies · weapons(무기8/패시브12/진화8) · bosses · story · sprites(자동생성)
src/game/                      state · player · enemies · weapons · pickups · hazards · boss · spawner · progression · effects · render · game
src/ui/                        hud(캔버스) · screens(DOM)
tools/bake_sprites.py          스프라이트 시트 → 트리밍·축소된 WebP 아틀라스 + 프레임/앵커 메타데이터
tools/optimize_assets.sh       배경/일러스트 WebP, BGM 96kbps 재인코딩
```

### 성능
- 고정 타임스텝 + dt 기반 이동 → 120/144Hz 기기에서도 동일 속도
- 오브젝트 풀 + swap-remove, 공간 그리드 충돌/밀어내기, 화면 밖 컬링
- `shadowBlur`/`ctx.filter` 미사용: 색조·피격 플래시·좌우 반전 변형을 로드 시 사전 렌더
- 그림자 일괄 path, 안개+비네트 단일 오버레이, 데미지 숫자/파티클/데칼 상한(품질 설정별)
- 에셋: 스프라이트 1.5MB → 0.88MB, 배경 4.0MB → 0.38MB, BGM 4.4MB → 2.8MB
- 측정(헤드리스, GPU 없음): 적 400+ 에서 업데이트 ~1.5ms + 렌더 JS ~2.5ms / 프레임

### 밸런스 (자동 봇 시뮬레이션 기준)
- 스테이지 1~3 클리어, 보스 처치 ~25~35초, 스테이지 4 보스부터 진화 무기 필요
- 사망 시 해당 스테이지 시작 시점 빌드로 재도전, 타이틀에서 이어하기 지원
