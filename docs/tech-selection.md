# 시작 테크 선택 · 공명 · 난이도 재조정

## 의도
뱀파이어 서바이버즈처럼 "어떤 빌드를 타느냐"가 결과를 가르도록 설계했다. 시작 선택이 성장 방향을 정하고,
한 계열에 집중하면 보너스가 단계적으로 쌓이며, 여러 계열을 섞으면 그 보너스를 받지 못한다.

## 시작 테크 (src/data/techs.js)
| 테크 | 시작 조합 | 공명 계열 무기 / 보조 | 보너스 대상 태그 |
| --- | --- | --- | --- |
| 탄막 사수 | 산탄총 + 탄창 확장 | 산탄총·노획 소총·쌍권총 / 탄창 확장·조준경·집중 | projectile |
| 연꽃 정원 | 연꽃 가시 + 재생하는 살점 | 연꽃 가시·꽃잎포·뼈 톱날 / 재생·꽃가루·썩은 심장 | orbit, beam |
| 역병 화염 | 화염병 + 확산 | 화염병·독가스·꽃잎포 / 확산·회전 수액·철갑 피부 | field |
| 처형자 | 쌍권총 + 집중 | 쌍권총·노획 소총·뼈 톱날 / 집중·날 연마·광기 | projectile, blade |
| 도살자 | 뼈 톱날 + 날 연마 | 뼈 톱날·산탄총·연꽃 가시 / 날 연마·철갑 피부·썩은 심장 | blade, orbit |

- 시작 패시브는 시작 무기의 진화 짝이다. 시작부터 공명 2/6(I단계).
- 공명 수 = 보유 계열 무기 + 보유 계열 보조 (최대 6). 융합 결과물은 소모한 계열 무기 수만큼 계속 기여한다.
- I/II/III 단계(2/4/6개) 보너스는 누적. `weapon.*` 은 태그가 맞는 무기에만, `player.*` 는 캐릭터 전체에 적용.
- 레벨업 카드: 계열 아이템 가중치 ×1.7, 공명 2 이상이면 다른 계열 신규 무기 ×0.6. 카드에 "✦ 계열" 표시.
- `newRun(stage)` 처럼 테크를 생략하면 예전과 같은 산탄총 단독 시작(테크 없음, 가중치 변화 없음).

## 난이도
| 항목 | 이전 | 현재 |
| --- | --- | --- |
| 레벨업 비용 | 8 + 7(L−1) + 10·max(0,L−20) + 16·max(0,L−40) | 10 + 10(L−1) + 20·max(0,L−20) + 40·max(0,L−35) |
| Lv1 / 10 / 20 / 40 | 8 / 71 / 141 / 481 | 10 / 100 / 200 / 1000 |
| 보스 경험치 젬 | 24개 | 16개 |
| 1·2스테이지 완화 (HP/속도/피해) | 0.85·0.85·0.70 / 0.92·0.92·0.85 | 0.95·0.90·0.85 / 1.00·0.95·0.95 |
| 스테이지 내 HP 상승 | +50% | +70% |

`node tools/run-progression-audit.mjs 40 --compact` (이전 → 현재, 중앙 시나리오):
런 전체 선택 횟수 77 → 60 (−22%). 집중(focused) 정책은 여전히 보스 10 전 최종 융합 3개에 도달,
분산(scattered) 정책은 대부분 1~2개 → 집중 빌드와 분산 빌드의 격차가 커졌다. 공명 보너스는 이 감사 모델에 포함되지 않으므로
실제 플레이에서는 집중 빌드가 더 유리하다.

## 모바일 렌더링 예산
아군 장판(화염·독가스)이 겹치면 픽셀 채우기 비용이 폭증한다(지옥 불꽃길 최대 34장). 화질 단계별로 화면 면적 기준 예산을 둔다.

| 단계 | 장판 글로우 | 장판 채우기 | 안개·비네트 |
| --- | --- | --- | --- |
| 0 (고화질) | 1.2 화면 | 3 화면 | 표시 |
| 1 (모바일 기본) | 0.6 | 1.6 | 표시 |
| 2 (자동 하향) | 0.3 | 1.0 | 생략 |

예산을 넘은 아군 장판은 얇은 외곽선만 그린다. 적 산성 장판과 보스 예고는 예산과 무관하게 항상 전부 그린다. 판정·피해는 변하지 않는다.

측정 (Chromium, 844×390, 6개 융합 무기 + 장판 60~100개, 캔버스 drawImage/fillRect 면적 계측):
프레임당 채운 픽셀 약 7.9 화면 → 2.7 화면 (−66%). 바닥 채우기 여백도 실제 보이는 영역으로 줄였다.
이 컨테이너에는 GPU가 없어 실제 휴대폰 FPS는 측정하지 못했다.

## 함께 고친 버그

## 난이도 · 각인 · 보스 체력 (3차 조정)

### 난이도 (테크 선택 화면에서 선택)
적은 약해지지 않는다. 난이도가 오를수록 **레벨업 경험치**가 늘고 보스 상자 강화 수가 줄어든다.

| 난이도 | 레벨업 경험치 | 보스 상자 확정 강화 | 추가 강화 확률 |
|---|---|---|---|
| 쉬움 (기존 기준) | ×1 | 기본 | ×1 |
| 보통 | ×1.8 | -1 | ×0.7 |
| 어려움 | ×3 | -2 | ×0.45 |
| 헬 | ×5 | -3 (최소 1) | ×0.25 |

진행 감사(`tools/run-progression-audit.mjs`, 30회, 수집률 85%) 기준 10스테이지 보스 전 선택 횟수 중앙값: 쉬움 60 · 보통 50 · 어려움 42 · 헬 36.
계획 빌드의 진화 완성 수는 쉬움 3 → 헬 0~1, 산만한 빌드는 어려움부터 대부분 0.

### 테크 각인 (성장 방향)
테크 태그가 맞는 무기는 Lv3/5/7에서 테크별로 다른 각인이 열린다 (`src/data/techs.js` `imprints`).
레벨업 카드에 `✦ 각인 이름`으로 표시. 태그가 맞지 않는 무기는 **부조화 피해 -20%**, 다른 계열 신규 무기 카드는 덜 나오고(×0.35) 계열 카드는 더 나오며(×2.2) 4레벨마다 계열 카드 1장 보장.

### 기타
- 보스 체력 ×10 (`BOSS_HP_MULTIPLIER`). 보스전 중 일반 몹 경험치 ×0.5. 레퍼런스 빌드 기준 처치 시간 약 44~115초.
- 회복 보급은 HP 30% 이하일 때만 등장.
- 융합(최종 무기)에 쓴 재료 무기는 다시 등장하지 않고, 미획득 아이템 비중이 2배.
- 독안개 지속 4초 → 20초.
- 사수 토끼의 조준선 경고 제거. 자폭 토끼는 꽃돼지 방향으로 추적하며 더 길게 돌진(320px/s × 1.3s).
